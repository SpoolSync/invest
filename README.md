# Investments

Part of Pixora. Tracks what you own across TFSA, RRSP, FHSA, RESP, non-registered and savings accounts: value, gains, allocation, contribution room and dividends.

- Works offline; installs to the home screen.
- Encrypted on the phone with your Pixora passcode before it syncs. The server, the project owner and any AI can't read it.
- Doesn't connect to any broker or bank. Import a holdings CSV, or type them in.
- A tracker, not financial advice.

Live: https://spoolsync.github.io/invest/
